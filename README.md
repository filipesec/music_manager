# 🎵 Music Manager

Aplicativo de gerenciamento de músicas com banco de dados local (Drift), player de áudio, temas claro/escuro e busca integrada.

---

## 📋 Funcionalidades

- ✅ **CRUD completo**
- 🎵 **Player de áudio**
- 🖼️ **Upload de capa** e **arquivo MP3** (Caminhos)
- 🔍 **Busca por nome ou artista**
- 🎛️ **Filtro por gênero**
- 🌗 **Tema claro/escuro**
- 📊 **Visualizador de banco**

---

## 🛠️ Tecnologias

| Tecnologia | Função |
|------------|--------|
| [Flutter](https://flutter.dev) | Framework UI |
| [Drift](https://drift.simonbinder.eu) | ORM para SQLite |
| [BLoC](https://pub.dev/packages/flutter_bloc) | Gerenciamento de estado (tema) |
| [just_audio](https://pub.dev/packages/just_audio) | Player de áudio |
| [file_picker](https://pub.dev/packages/file_picker) | Seleção de arquivos MP3 |
| [image_picker](https://pub.dev/packages/image_picker) | Seleção de capa |
